## Couleurs de base et neutres (Fond, Texte, Contraste)

| Couleur | Utilisation typique en UI | Code RGB | Code Hexadécimal (pour référence) |
| :--- | :--- | :--- | :--- |
| **Blanc pur** |{rgb(255, 255, 255)}$ | `#FFFFFF` |
| **Noir pur** | {rgb(0, 0, 0)}$ | `#000000` |
| **Gris foncé** | {rgb(45, 45, 45)}$ | `#2D2D2D` |
| **Gris moyen** | {rgb(128, 128, 128)}$ | `#808080` |
| **Gris clair** | {rgb(240, 240, 240)}$ | `#F0F0F0` |

***

## Couleurs sémantiques (État et Action)

Ces couleurs sont essentielles pour donner un **feedback** visuel à l'utilisateur sur l'état du système ou de ses actions.

| Couleur | Signification en UI | Code RGB (Exemple) | Code Hexadécimal (Exemple) |
| :--- | :--- | :--- | :--- |
| **Bleu (Principal)** | {rgb(0, 123, 255)}$ | `#007BFF` |
| **Vert (Succès)** | {rgb(40, 167, 69)}$ | `#28A745` |
| **Rouge (Erreur)** | {rgb(220, 53, 69)}$ | `#DC3545` |
| **Jaune/Orange (Avertissement)** | {rgb(255, 193, 7)}$ | `#FFC107` |

***

## Couleurs tendances (Exemples pour accent)

Bien qu'une UI puisse adopter n'importe quelle couleur principale, ces exemples de couleurs vives et saturées sont souvent utilisées comme **couleurs d'accentuation** ou couleurs principales de marque.

| Couleur | Remarque | Code RGB (Exemple) | Code Hexadécimal (Exemple) |
| :--- | :--- | :--- | :--- |
| **Bleu Profond** | {rgb(6, 54, 101)}$ | `#063665` |
| **Cyan Vif (Aqua)** | {rgb(0, 191, 255)}$ | `#00BFFF` |
| **Vert Menthe** | {rgb(104, 206, 186)}$ | `#68CEBA` |
| **Magenta/Fuchsia** | {rgb(255, 0, 255)}$ | `#FF00FF` |
